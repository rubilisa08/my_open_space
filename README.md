## 안 나온 자리
- `.sog` 변환이 계속 실패했습니다. `.sog`의 색상 압축은 GPU(WebGPU/Vulkan)를 거쳐야 하는데, 시도한 세 환경 모두에서 막혔습니다.
  1. 로컬 PC 내장 GPU(Intel Iris Xe): 압축 도중 매번 드라이버가 타임아웃(TDR)으로 죽음 (`DXGI_ERROR_DEVICE_HUNG`)
  2. 로컬 PC + 소프트웨어 Vulkan(CPU로 GPU 흉내): 에러는 안 나지만 진행이 멈춘 채 30분 넘게 응답 없음
  3. Colab T4 GPU: 3DGS 학습(CUDA 경로)은 문제없었지만, `.sog`가 쓰는 Vulkan(그래픽 경로)은 컨테이너에 드라이버가 아예 없어 실패, 소프트웨어 Vulkan을 설치해도 로컬과 같은 증상(멈춤)이 재현됨
  
  즉 GPU 자체가 아니라 이 변환 도구가 요구하는 Vulkan 그래픽 드라이버가 세 환경 모두에서 정상 동작하지 않아서 막힌 것으로 판단했습니다. 같은 알갱이 개수를 가진 `.spz`(3.2MB, `.ply` 대비 91% 감소)로 대체 배포했습니다.
